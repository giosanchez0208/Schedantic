# Bare-weekday rule now RATIFIED in ANNOTATION_GUIDE.md:
#   A bare SINGLE weekday ("THURS lunch", "Wed stock") is tagged DATE, read as a
#   one-off on the coming Thursday. A multi-day code ("MWF", "TTh"), an explicit
#   "every", or a count/until bound is tagged RECUR. Rationale: genuine recurrence
#   in this register almost always carries "every" or a multi-day cluster, while a
#   lone weekday usually means the next one. This disagrees with the parser, which
#   makes every weekday RECUR. Flagging so it can be ratified or overturned.
